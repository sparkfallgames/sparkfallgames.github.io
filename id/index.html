Saya pengembang solo di balik Sparkfall Games. Setiap game dan alat 100% native untuk iOS, dilokalkan ke 34 bahasa, dan dibangun dengan satu aturan: data Anda tetap di perangkat Anda.

Desain, kode, gambar, dan musik semuanya saya kerjakan sendiri, sehingga setiap aplikasi tetap kecil, cepat, dan jujur. Tanpa investor, tanpa trik pertumbuhan — saat membeli aplikasi saya, Anda adalah pelanggan, bukan produk.
